# 📊 Análise de KPIs em E-commerce  

## 🚀 Sobre o Projeto  
Este projeto realiza uma **análise exploratória de dados (EDA)** em um dataset fictício de **2.500 pedidos de e-commerce**.  
O objetivo foi **identificar os principais KPIs de negócio** e traduzir números em **insights estratégicos** para tomada de decisão.  

---

## 🛠️ Tecnologias Utilizadas  
- **Python 3.11**  
- **Pandas** → manipulação de dados  
- **Matplotlib** → visualizações  

---

## 📈 KPIs Gerais  
- **Pedidos:** 2.500  
- **Clientes Únicos:** 1.200  
- **Receita Total:** R$ 2.9M+  
- **Lucro Líquido Total:** R$ 970K+  
- **Margem Bruta Geral:** 32.8%  
- **Ticket Médio:** R$ 1.000+  
- **Taxa de Devolução:** 8.7%  

---

## 🔍 Principais Insights  

### 1. Receita e Lucro por Categoria  
- Eletrônicos lideram em **receita absoluta**.  
- Beleza apresenta **margens mais altas (~49%)**, mesmo com menor receita.  

### 2. Ticket Médio por Canal  
- **Marketplace** → maior ticket médio (R$ 1.468).  
- Canais sociais → compras menores, mas com grande alcance.  

### 3. Taxa de Devolução  
- **Moda** e **Eletrônicos** são os campeões de devoluções → ajuste de qualidade e logística é essencial.  

### 4. ROI de Marketing por Canal  
- **WhatsApp** → ROI extremamente eficiente (187+).  
- **Instagram** → ROI baixo/negativo → necessidade de otimização de campanhas.  

### 5. Receita Mensal (Tendência)  
- Queda nos últimos 3 meses.  
- Indício de **sazonalidade** → planejar campanhas antecipadas em datas fortes.  

### 6. Clientes Frequentes (Top Compradores)  
- Receita concentrada em **poucos clientes VIPs**.  
- Oportunidade para programas de fidelização e cross-sell.  

### 7. Margem Bruta por Categoria  
- **Beleza** → margens altíssimas → ótimo para promoções agressivas.  
- **Eletrônicos** → margens menores → estratégia deve focar em **volume**, não em desconto.
